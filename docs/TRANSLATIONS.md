# Translations

Gantt-It speaks English, French, Spanish and German (spec §2.6, decision #22).
The French, Spanish and German texts were written for v1 and still need a native
review; this note records the choices a reviewer should check.

## Two languages, two sources

| | UI language | Chart language |
|---|---|---|
| Decides | every window, dialog, message, tooltip and the Revit Undo names | the text drawn on the chart |
| Comes from | Revit's language (`Application.Language`): French, German or Spanish Revit → that language, anything else → English | Settings › Chart language, stored per project (`chartLanguage` in the settings JSON) |
| Stored in | `src/GanttIt.Revit/Resources/Strings*.resx`, `src/GanttIt.Core/Resources/CoreStrings*.resx` | hard-coded tables in `src/GanttIt.Core/Localization/ChartText.cs` |

A new project's chart language starts as the UI language; settings saved before
this field existed read as English. The debug build honours `GANTTIT_UI_LANG=en|fr|es|de`
to override Revit's language.

Editing strings: change all four `.resx` files (the Core tests fail on a missing
key, an empty value or a placeholder mismatch), then run `python3 tools/gen_strings.py`
to refresh the typed accessors.

## Chart text

| | English | French | Spanish | German |
|---|---|---|---|---|
| Name column | Section | Section | Sección | Abschnitt |
| Start column | Start | Début | Inicio | Beginn |
| End column | End | Fin | Fin | Ende |
| Duration column | Dur | Durée | Dur. | Dauer |
| Month (top tier) | October 2026 · Oct 2026 · Oct '26 | octobre 2026 · oct. 2026 · oct. 26 | octubre 2026 · oct 2026 · oct 26 | Oktober 2026 · Okt 2026 · Okt '26 |
| Month (lower tier) | January · Jan | janvier · janv. | enero · ene | Januar · Jan |
| Week (top tier) | 19 Oct | 19 oct. | 19 oct | 19. Okt |
| Quarter | Q1 | T1 | T1 | Q1 |
| Year | 2026 · '26 | 2026 | 2026 | 2026 · '26 |
| Default chart name | Gantt Chart 1 | Diagramme de Gantt 1 | Diagrama de Gantt 1 | Gantt-Diagramm 1 |
| Default section name | Section 1 | Section 1 | Sección 1 | Abschnitt 1 |

Month abbreviations: French follows the Imprimerie nationale forms (janv. févr.
mars avr. mai juin juil. août sept. oct. nov. déc.), Spanish the CLDR forms
without a period (ene feb mar abr may jun jul ago sept oct nov dic), German the
three-letter forms (Jan Feb Mär Apr Mai Jun Jul Aug Sep Okt Nov Dez). Month names
are lower case in French and Spanish. French and Spanish write years in full:
the apostrophe year is an anglicism there, so a crowded year tier labels fewer
years instead. Day names (for `ddd`/`dddd` in a custom date pattern) come from
the same tables. Digits and separators are always invariant.

The default chart and section names are filled in when a chart or section is
created; once kept or edited they are user text and are never translated again.

### Never translated

`Gantt-It Fill #RRGGBB` (the filled region types) and any other element or type
name Gantt-It uses to find its own elements are identifiers, not chart text.
Translating them would make a model regenerated by users of different languages
collect duplicate types. The ribbon panel and button keep the product name
`Gantt-It`; the Revit Undo names keep the `Gantt-It:` prefix.

Conventions: French uses « guillemets » with no-break spaces and a no-break space
before `:` `;` `?`; German uses „Anführungszeichen“ and the formal *Sie*; Spanish
uses straight quotes and the formal imperative (*elija*, *abra*). Key names in
dialogs follow Windows: Échap, Esc, Alt+Bas / Alt+Abajo / Alt+Nach-unten.

Short forms chosen for fixed-width places (the `.resx` comments mark them):
the home card's **Open view** button (Ouvrir / Abrir / Öffnen, the tooltip says
what it opens), the editor's **Timeline width** and **Name column max** labels,
and the two link column headers (72 px, two lines).

## Not translated in v1

Low-level technical details that come from Windows or .NET (an exception's own
message, the name of a GDI call that failed while picking from the screen) and
messages Revit itself returns (already in Revit's language) are shown as they
come, inside a translated sentence. Internal invariant exceptions (e.g. refusing
to serialize a newer schema) and the debug-only Self-Test UI stay in English.
